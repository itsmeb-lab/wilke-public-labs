# Library museum passes and timed tickets

The guide compares five named routes for getting and redeeming a library museum pass. Rules describe the exact library, venue or named multi-venue program. In the Burlington County comparison, confirm the individual venue’s terms. Missing evidence produces an unconfirmed card.

- [Published guide](https://itsmeb-lab.github.io/wilke-public-labs/library-museum-passes/)
- [Reviewed catalog](./catalog.json)
- [Comparison CSV](./comparison.csv)

Run `node scripts/update-library-museum-passes.mjs --check` from the repository root. Edit the catalog, regenerate with `--write`, and update the [draft WordPress exchange](../wordpress-exchange/) after a review.
