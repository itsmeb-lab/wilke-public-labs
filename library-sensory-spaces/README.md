# Library Sensory Rooms and Quiet Hours

Compare walk-in access, reservations, library card rules, supervision and visit time at six named library sensory spaces and quiet hours. Rules apply to the named program. Missing evidence appears as an unconfirmed answer.

- [Published guide](https://itsmeb-lab.github.io/wilke-public-labs/library-sensory-spaces/)
- [Reviewed catalog](./catalog.json)
- [Comparison CSV](./comparison.csv)

From the repository root, run `node scripts/update-library-sensory-spaces.mjs --check`. After editing the reviewed catalog, regenerate with `--write` and update the WordPress draft exchange.
