Do library sensory rooms and quiet hours need a booking?

One library can have two sensory spaces with different access rules. Durham’s Main Library has both a walk-in calming room and a room that requires a reservation with an eligible card.

Check the exact room, branch or event. A quiet hour can change conditions in a shared library space for a set time.

A room, quieter hours and a kit serve different visits

If you need headphones or other items while you are at a library, look for its own lending instructions. For example, Grapevine Public Library checks out in-library sensory bags at the circulation desk without requiring a library card.

Ask the operator if specific equipment, lights or sound matter for your visit. Check the current listing before planning around scheduled sessions.
