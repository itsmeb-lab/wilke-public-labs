# Where to Donate a Used or Broken Bicycle

Compare bicycle donation rules for rideable bikes, heavy rust, usable spare parts, used helmets and pickup at named community bike shops. Rules apply to the named program. Missing evidence appears as an unconfirmed answer.

- [Published guide](https://itsmeb-lab.github.io/wilke-public-labs/used-bicycle-donations/)
- [Reviewed catalog](./catalog.json)
- [Comparison CSV](./comparison.csv)

From the repository root, run `node scripts/update-used-bicycle-donations.mjs --check`. After editing the reviewed catalog, regenerate with `--write` and update the WordPress draft exchange.
