# Food-scrap drop-off guide

[Compare the programs](https://itsmeb-lab.github.io/wilke-public-labs/food-scrap-drop-off/) for five selected materials. These are public drop-off instructions, scoped to the six named operator routes. The guide distinguishes the location source from the materials source when they differ. The Carrboro note explains why the older seasonal location listing and the town’s current site instructions both appear.

Review primary policies before updating a row. Rebuild the HTML and CSV with `node scripts/update-food-scrap.mjs --write`, then run `--check` and `npm test`. [Source impact and release verification](../COMPARISON-MAINTENANCE.md) cover this guide.
