# Borrow a State or Provincial Park Pass from a Public Library

Compare library park passes in Wisconsin, South Carolina, California, Colorado, Maryland, New York and Ontario by vehicle, holds, loan length and park access. Rules apply to the named program. Missing evidence appears as an unconfirmed answer.

- [Published guide](https://itsmeb-lab.github.io/wilke-public-labs/library-state-park-passes/)
- [Reviewed catalog](./catalog.json)
- [Comparison CSV](./comparison.csv)

From the repository root, run `node scripts/update-library-state-park-passes.mjs --check`. After editing the reviewed catalog, regenerate with `--write` and update the WordPress draft exchange.
