# Digitize VHS and Camcorder Tapes at a Library Memory Lab

Find named library memory labs with VHS, MiniDV or Hi8 equipment. Compare walk-ins, first-visit requirements and ways to save files. Rules apply to the named program. Missing evidence appears as an unconfirmed answer.

- [Published guide](https://itsmeb-lab.github.io/wilke-public-labs/library-memory-labs/)
- [Reviewed catalog](./catalog.json)
- [Comparison CSV](./comparison.csv)

From the repository root, run `node scripts/update-library-memory-labs.mjs --check`. After editing the reviewed catalog, regenerate with `--write` and update the WordPress draft exchange.
