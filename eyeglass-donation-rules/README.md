# Eyeglass and Hearing Aid Donation Rules

Compare broken frames, loose lenses, cases, sunglasses and hearing aid donation rules at six named collection programs. Rules apply to the named program. Missing evidence appears as an unconfirmed answer.

- [Published guide](https://itsmeb-lab.github.io/wilke-public-labs/eyeglass-donation-rules/)
- [Reviewed catalog](./catalog.json)
- [Comparison CSV](./comparison.csv)

From the repository root, run `node scripts/update-eyeglass-donations.mjs --check`. After editing the reviewed catalog, regenerate with `--write` and update the WordPress draft exchange.
