# Seed Library Rules for Borrowing and Returning

Compare library cards, packet limits, unused seed returns, saved seed donations and pickup instructions at eight seed libraries. Rules apply to the named program. Blank evidence renders an unconfirmed card.

- [Published guide](https://itsmeb-lab.github.io/wilke-public-labs/library-seed-borrowing/)
- [Reviewed catalog](./catalog.json)
- [Comparison CSV](./comparison.csv)

From the repository root, run `node scripts/update-library-seeds.mjs --check`. After editing the reviewed catalog, use `--write` and update the draft WordPress exchange.
