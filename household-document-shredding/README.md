# Where to Shred Household Documents

Compare document shredding drop-offs and events by appointment, staples, box limits, business eligibility and whether you can watch. Rules apply to the named program. Missing evidence appears as an unconfirmed answer.

- [Published guide](https://itsmeb-lab.github.io/wilke-public-labs/household-document-shredding/)
- [Reviewed catalog](./catalog.json)
- [Comparison CSV](./comparison.csv)

From the repository root, run `node scripts/update-household-document-shredding.mjs --check`. After editing the reviewed catalog, regenerate with `--write` and update the WordPress draft exchange.
