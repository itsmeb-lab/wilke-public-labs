# Published Policy Lab

A browser-only example of task-specific answers from checked primary policies. Eleven sample places and programs in South Carolina, North Carolina and Kentucky cover recycling, notary, printing, borrowing and room-use rules.

**Live page:** https://itsmeb-lab.github.io/wilke-public-labs/published-policy-lab/

## Use it

Choose a task, place and optional visit date. Each answer separates:

- whether the source describes, excludes or does not settle the requested task;
- the weekday pattern and applicable supplied closure calendar;
- live availability, which remains unverified.

A source-directed alternate location is offered only when the snapshot explicitly supports the same task in the same jurisdiction. This is not distance-based routing.

## Scope and privacy

The snapshot was checked on November 25, 2026. It is a limited educational example, not an official directory, legal eligibility decision, live opening-hours feed or booking service. It does not decide whether an individual document can be notarized. Operators may change rules or decline particular requests.

Choices are processed on the page. Each answer offers a share link containing the task, place and optional date. Opening that link restores those choices; changing the controls creates a new link in the answer. Your browser may retain visited links in its ordinary history. No document upload, login, payment, API call, added analytics or stored profile is used. Hosting providers can record ordinary web requests. Source links open third-party sites.

This independently written module projects a checked data snapshot; it does not run a publishing/scoring system or claim nationwide coverage.

## Sources

All source URLs and check dates are in [data.mjs](./data.mjs). Eleven sources cover agency or library policies plus the county's dated closure PDF. Check dates describe this lab's review, not the agencies' update dates. A missing field stays unknown; an omitted holiday is not proof a site is open.

The 2026 closure list is not reused for 2027. Printing does not inherit notary-service hours. Morehead, Kentucky is not mapped to a same-named county in another state.

## Run and verify

From the repository root:

```bash
npm test
python -m http.server 8080
```

Open `http://localhost:8080/published-policy-lab/`. Use a server for native ES modules; opening HTML directly from disk may not load them.

Tests cover policy fixtures and the actual browser module with a minimal DOM. That fixture is separate from real-browser review. Tests do not contact agencies or verify present-day service availability.

## Update procedure

1. Reopen the exact primary source; confirm the place, state, task and effective year.
2. Record the source-check date and change only supported fields.
3. Preserve exclusions and unknowns; do not infer one branch's policy for another.
4. Run tests and review browser output before publishing.
5. Correct or remove unsupported records rather than expanding uncertain combinations.

Report source mismatches through the public repository. Include the public source URL and affected task, never identity documents or private personal details.

## Plain-text policy snapshot

The visible eleven-entry rule browser is generated by `renderPolicySnapshot(catalog)` in `snapshot.mjs` and checked into `index.html` between `POLICY-SNAPSHOT` markers. It exposes all 25 reviewed place/task joins without JavaScript. A test requires the saved markup to exactly match the catalog projection, so a data edit must refresh the snapshot before CI passes. This is one canonical tool page, not 25 additional URLs. The static notes omit visit schedules; the interactive checker applies the separately supplied date/closure rules. All live availability remains unknown.

## Borrowing program scope

The Charlotte Mecklenburg hotspot and Clayton Library of Things entries describe program rules. They do not name a specific pickup address, show live stock, predict a wait time or calculate charges. A shared scope note is shown in both the interactive answer and static cards. The operator's catalog and current item-specific policy remain the handoff. The snapshot has eleven place/program entries, 25 joined policy records and eleven source documents.

## Share one checked view

Use **Link to this policy view** in an answer to copy or bookmark its task, place and optional date. The fragment names only records in this catalog; it is not a live availability claim. Unknown, repeated, malformed or unsupported selections show a refusal rather than a substituted answer. These fragments share one canonical page and add no sitemap URLs. A saved link uses the current checked snapshot when reopened; it does not preserve a historical policy version.

## Meeting purpose and dated notices

Durham's commercial meeting fees do not permit private meetings or charging attendees. Individual/private study uses a separate room category. Davidson excludes commercial meetings; its meeting-room source does not settle private study access. Program entries are not branch bookings.

The Durham calendar records the source's 2026 full closures and two early closings, plus its explicit January 1, 2027 closure. Known full closures are displayed even without a weekly schedule. Early closing stays partial-day; unlisted dates stay unknown. Branch-only maintenance notices are not generalized county-wide. The source's relative 'today' badge is not used as date-specific proof.
