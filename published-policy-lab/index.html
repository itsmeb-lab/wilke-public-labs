Charlotte Mecklenburg Library — hotspot program

Program rules · Mecklenburg County, NC

Program-level rules. Confirm the pickup location and current item availability with the operator.

  • Hotspot borrowing

    Service described

    The library describes a seven-day hotspot loan, subject to borrower requirements and the reservation queue.

    Borrowers must be 18+ with a valid Charlotte Mecklenburg Library card, current government photo ID and a library-account balance below $10.

    The limit is one hotspot per borrower; the published loan is seven days without renewal.

    Return the equipment to staff at a library location, rather than a book drop. Use is restricted to the continental United States.

    Check the source for overdue service cutoff and replacement charges. The lab does not calculate fees or predict stock and wait time.

    Charlotte Mecklenburg Library — hotspot borrowing rules

What this page can tell you

Each answer uses a small, dated policy snapshot. “Described” means a source discusses the service; it does not guarantee your request will be accepted. Missing fees, unsupported document types and unavailable closure calendars stay unknown.
