# Tool Library Rules for Borrowing and Paying

Compare household eligibility, free checkout, membership, fees, reservations and returns at six tool lending programs. Rules apply to the named program. Blank evidence renders an unconfirmed card.

- [Published guide](https://itsmeb-lab.github.io/wilke-public-labs/tool-library-borrowing/)
- [Reviewed catalog](./catalog.json)
- [Comparison CSV](./comparison.csv)

From the repository root, run `node scripts/update-tool-library.mjs --check`. After editing the reviewed catalog, use `--write` and update the draft WordPress exchange.
